
# Placement Readiness Tracker

## Project Overview
The Placement Readiness Tracker is a Python-based
command-line application designed to store student
practice-test scores and evaluate placement readiness.

## Features
- Stores student records using dictionaries.
- Accepts additional student information.
- Validates scores between 0 and 100.
- Calculates student averages.
- Assigns grades based on average scores.
- Identifies the top-performing student.
- Identifies students needing extra practice.
- Calculates the second-highest distinct score.

## Technologies Used
- Python
- Git
- GitHub

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Run the following command:

python main.py
